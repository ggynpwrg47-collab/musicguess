# Fest eingebaute Song-Listen

Jede Datei `*.musicguess.json` in diesem Ordner wird beim Build in die App gepackt und erscheint auf
**jedem Gerät** unter „Song-Listen“ (Markierung „Fest eingebaut“), also z. B. auch am Handy über die
GitHub-Pages-Adresse.

So kommt eine Liste hierher:

1. Am PC in Music Guess die Liste importieren und die Jahre prüfen.
2. In der Liste auf **„Exportieren (für alle Geräte)“** klicken. Es wird eine Datei wie
   `roadtrip-mix.musicguess.json` heruntergeladen.
3. Die Datei in diesen Ordner legen und committen/pushen. Bei GitHub geht das auch im Browser:
   Ordner `src/decks` öffnen → **„Add file → Upload files“** → Datei hineinziehen → **„Commit changes“**.
4. GitHub Pages baut die Seite automatisch neu; nach ca. einer Minute ist die Liste auf allen Geräten da.

Ändern: Liste in der App kopieren, bearbeiten, neu exportieren und die Datei hier ersetzen.
Entfernen: Datei hier löschen.

**Hinweis:** Alles in diesem Ordner ist Teil der veröffentlichten Seite. Wer die Adresse kennt, kann diese
Listen sehen (nur Titel, Interpret, Jahr und Links – keine Musik, keine Konto-Daten).
